I advocate for a "Do it once, do it right" approach.  This shines through in how I develop software.  This page is essentially a more organized version of my public gitub repositories that I would be happy for others to use.   

## Useful Modules 

### Mathematica Plotting 
[Package](https://github.com/baitken18/TheoryPlot) 

This package essentially enforces my Mathematica plotting defaults.  The goal is to have functionality of switch between a few different plot styles.  These plot styles would include sizes required for different journals.  There would also be plots that fit within my beamer template.  

### Python Plotting 

I don't typically use python anymore, but I still have some software that I think looks good.  It builds off of the scienceplots github package.

## Templates 

I have a few templates that I have made for documents I found myself using frequently.  The presentations are designed using UVic colours, but this is designed to be easily modified to match your home institution, if desired.
